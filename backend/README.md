# Автодополнение адреса (справочник ФИАС)

При заполнении поля «Адрес» в карточке вызова работает автодополнение адресов
из локального справочника ФИАС на SQLite.

## Расположение БД

Файл `fias_94.db` должен лежать в `backend/data/`:

```
backend/data/fias_94.db
```

Этот файл большой (≈ 90 МБ) и, как и другие рантайм-данные, **не хранится в git**
(см. правило `/backend/data/` в корневом `.gitignore`). При разворачивании проекта
файл нужно положить вручную (скопировать из архива/бэкапа).

Путь к БД можно переопределить переменной окружения `ADDRESS_DB_PATH`.

## Эндпоинт

- `GET /api/address/autocomplete?q=...&limit=...` — поиск адреса по строке.
  Требует авторизации и права `calls.view`. Возвращает
  `{ query, tookMs, results: [{ display, type, aoguid, ... }] }`.

Поле `display` — готовая строка адреса (например `г. Луганск, ул. Оборонная, д. 5`).

## Реализация

- Роут: `src/routes/addressRoutes.js`
- Контроллер: `src/controllers/addressController.js`
- Логика поиска (нормализация, иерархический поиск, дома): `src/services/addressAutocompleteService.js`

БД открывает драйвер в таком порядке:
1. встроенный `node:sqlite` (доступен с Node 24, работает без флагов);
2. `better-sqlite3` (запасной, для Node 20–23).

`better-sqlite3` добавлен в `backend/package.json`, поэтому на проде установится
при `npm install`. Собранные бинарники для Ubuntu поставляются в пакете, компилятор
не нужен.

При первом открытии БД сервис автоматически заполняет нормализованные
колонки/индексы (`addrobj.name_lower`, `house.number_lower`), если их ещё нет.

Если файл БД отсутствует или не читается — сервис возвращает пустой список, не
роняя запуск сервера.

## Диагностика (важно для продакшена)

Симптом «ответ 200, но пустой `results`» означает, что SQLite-БД не открылась.
Причины и что делать:

1. **Файла `fias_94.db` нет на сервере.** Он в `.gitignore` и его выкатывают
   вручную (архив/rsync), а не через git. Положите файл в `backend/data/`
   относительно рабочего каталога бэкенда (или задайте `ADDRESS_DB_PATH`).
   **Внимание:** у некоторых драйверов открытие «пустого» пути создаёт файл — сервис
   заметит это и сообщит «не является базой ФИАС (нет таблицы addrobj)».
2. **Версия Node на сервере < 24.** Встроенный `node:sqlite` недоступен (или требует
   флаг `--experimental-sqlite` на Node 22). Решение: обновить Node до 24+ либо
   убедиться, что установлен `better-sqlite3` (см. выше).
3. **Нет прав на запись/чтение файла или каталога.** Проверьте владельца и `chmod`
   на `backend/data/fias_94.db`.

При старте сервер печатает в лог строку `[addressAutocomplete] База ФИАС готова: <путь> (драйвер: ...)`
или подробную ошибку с путём и причиной. Дополнительно можно проверить вручную:

```bash
curl -H "Authorization: Bearer <token>" "http://<host>:5000/api/address/autocomplete?q=Луганск&debug=1"
```

В ответе с `debug=1` появятся поля `available`, `error`, `dbPath` — по ним сразу
видно источник проблемы.
